🛠️ WebGPU Troubleshooting & Setup Guide

Google's LiteRT LLM Inference requires WebGPU acceleration in the browser. WebGPU is currently disabled, unsupported, or blocked on your system/browser. Follow the instructions below to enable it:

⚠️ Nvidia & Chrome Linux Conflict: Chrome's hardware acceleration often glitches or flickers on Linux with Nvidia drivers. Launching Chrome with --disable-gpu stops the flickering but disables WebGPU completely.

To force-enable WebGPU stably on Linux:

  1. Open chrome://flags in Chrome.
  2. Search for and Enable:
    • #enable-unsafe-webgpu
    • #enable-vulkan
  3. Search for #ozone-platform-hint and change it to X11 (forces stable rendering and bypasses Wayland sync glitches).
  4. Alternatively, run Chrome from terminal using these stability flags: 
    google-chrome --enable-unsafe-webgpu --enable-features=Vulkan --ozone-platform=x11
  5. If Chrome still flickers, disable GPU compositing but keep WebGPU active by running: 
    google-chrome --enable-unsafe-webgpu --enable-features=Vulkan --ozone-platform=x11 --disable-gpu-compositing

Ensure Hardware Acceleration is Active:

  1. Go to Chrome Settings > System.
  2. Toggle "Use graphics acceleration when available" to ON.
  3. Click Relaunch.
💡 Remote Access over Local Network (HTTP): WebGPU requires a Secure Context. If accessing a Windows host from another device (like an iPad/Tablet), you must permit insecure origins:
  • Open chrome://flags.
  • Search for #unsafely-treat-insecure-origin-as-secure.
  • Set it to Enabled and enter your server IP (e.g. https://192.168.1.15:8443 or http://192.168.1.15:8085) in the text box.
  • Relaunch Chrome.

WebGPU is supported on Apple Silicon and Intel Macs:

  • Safari 17+: Open Safari, go to Settings (Preferences) > Advanced. Tick "Show features for web developers". In the new Develop menu, select Feature Flags > WebGPU and ensure it is checked.
  • Chrome / Edge: Enabled by default. If disabled, ensure Hardware Acceleration is ON in browser Settings.

For Apple iPad / iPhone (iOS 17+):

  1. Open iPad/iPhone Settings > Safari > Advanced > Feature Flags (or Experimental Features).
  2. Toggle WebGPU to ON.
  3. Since LAN addresses (`https://192.168.x.x:8443` or `http://192.168.x.x:8085`) are insecure, Safari disables WebGPU. To bypass this, tap the Share button in Safari and choose Add to Home Screen. Opening the app from the Home Screen PWA icon runs it in a standalone sandbox with secure context privileges.
